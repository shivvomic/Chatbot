NimbusDesk Troubleshooting Guide

Version 3.0 - Updated 2025-07-15

I cannot sign in

If sign-in fails with the message Account locked, wait 30 minutes or ask an administrator to unlock the account from Settings > Members. If the message is Invalid credentials, use Forgot password to reset your password.

Email notifications are not arriving

First check that notifications@nimbusdesk.example is not blocked by your mail filter. Then confirm the notification type is enabled under Profile > Notifications. Bounced addresses are removed from notifications automatically after 3 consecutive bounces.

Webhook deliveries are failing

NimbusDesk retries a failed webhook delivery 5 times over 30 minutes. If all retries fail, the endpoint is disabled and an email is sent to the workspace owner. Error code WH-408 means your endpoint did not respond within 10 seconds.

CSV export fails

Error code EXP-413 means the export contains more than the allowed number of tickets. Narrow the date range and export again. See the API and Usage Limits article for the current maximum.

Search results are missing new tickets

Newly created tickets can take up to 2 minutes to appear in search. If a ticket is still missing after 10 minutes, contact support with the ticket number.
