NimbusDesk API and Usage Limits

Version 3.1 - Updated 2025-09-15

API rate limits

Rate limits are applied per workspace: Starter 60 requests per minute, Pro 300 requests per minute and Enterprise 1000 requests per minute. When the limit is exceeded the API returns HTTP 429 with a Retry-After header.

Pagination and exports

List endpoints return at most 100 records per request. A single export job can contain up to 10,000 tickets.

Webhooks

Pro workspaces can register up to 10 webhook endpoints. Enterprise workspaces can register up to 50. Starter workspaces cannot use webhooks.

Storage

Included storage per workspace is 10 GB for Starter, 100 GB for Pro and 1 TB for Enterprise. Maximum attachment size is 50 MB per file.
