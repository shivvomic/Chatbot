Setting Up SAML Single Sign-On

Version 3.0 - Updated 2025-06-20

Before you start

SAML 2.0 single sign-on requires the Pro or Enterprise plan and an Owner account. You need the metadata URL from your identity provider. Roles are described in the NimbusDesk User Manual 3.0.

Setup steps

Go to Settings > Security > Single sign-on, paste the identity provider metadata URL and select Test connection. After a successful test, select Enable. Keep one Owner account with password sign-in as a fallback until SSO is verified.

Attribute mapping

NimbusDesk requires the attributes email, first_name and last_name in the SAML response. Users are matched by email address. The attribute role is optional and maps to Agent, Admin or Owner.

Common errors

Error SSO-102 Invalid assertion usually means the clock on the identity provider differs from NimbusDesk by more than 5 minutes. Error SSO-210 means the email address in the assertion does not match any member.
