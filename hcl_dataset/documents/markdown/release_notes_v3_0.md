# NimbusDesk 3.0 Release Notes

## Highlights

SAML single sign-on is now available on the Pro plan, previously Enterprise only. AI suggested replies are available in beta for Enterprise workspaces.

## Limits and quotas

API rate limits are raised to 60 requests per minute for Starter, 300 requests per minute for Pro and 1000 requests per minute for Enterprise. The maximum attachment size is now 50 MB. CSV export now supports up to 10,000 tickets.

## Security

Password reset links now expire after 1 hour. Two-factor authentication is mandatory for Admin and Owner roles.

## Billing

The annual billing discount is now 20 percent for subscriptions that start on or after 1 July 2025.

## Deprecations

The legacy v1 API will be switched off on 31 December 2025. Integrations must migrate to the v2 API.
